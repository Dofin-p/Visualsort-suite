# VisualSort Suite — ソートアルゴリズム可視化プラットフォーム

**Live Demo:** [https://dofin-p.github.io/Visualsort-suite/](https://dofin-p.github.io/Visualsort-suite/)

VisualSort Suiteは、ソートアルゴリズムの「コードの処理」と「配列の変化」を **1ステップ単位で同期** させながら学べる、インタラクティブなWebアプリです。
単に「動いているのを眺める」のではなく、自分で入力値を決めて、好きなペースで1コマずつ確認できることを重視して設計しました。

## 開発背景

プログラミングの授業でソートを学んだとき、正直なところ「コードは読めるけど、何が起きているかよくわからない」という感覚が長く続きました。

特にしんどかったのが、二重ループの中でループ変数（`i`, `j`, `minIdx`）が変わるたびに、配列がどう変化したのかを頭の中で追いかけることです。結果が正しく並んでいても「なぜそうなったのか」がぼんやりしたまま次に進んでしまう——そんな経験から、「コードの動きと配列の変化を画面上で一致させたら、もう少し理解しやすくなるのでは」と思って作りました。

## 技術的なポイント

### 1. UIをフリーズさせずにアニメーションを動かす（非同期設計）

ソートのような処理をそのままループで回すと、計算が終わった瞬間に結果が出てしまい、「途中経過」が一切見えません。また、`setTimeout` や `setInterval` をそのまま使うだけだと、処理が積み重なってUIがブロックされることがあります。

本アプリでは、まずソートの各ステップを **Stepオブジェクトの配列として事前生成** し、再生時は `setInterval` でその配列を1つずつ参照してDOMを更新する方式をとっています。これにより、

- ソートロジックとUI描画が完全に分離される
- 「前へ / 次へ」の操作でも同じStep配列を参照するだけで済む
- 途中で一時停止・再開しても状態が崩れない

という構造を実現しています。いわゆる **Time-travel debugging** に近い考え方で、再生コントロールの実装がシンプルになる副次効果もありました。

### 2. コードとアニメーションの1行単位の同期

実行中のコード行をハイライトし、その瞬間に配列で起きていること（比較・交換・確定）をバーチャートで同時に表示します。「変数が更新される」→「配列がどう変わる」の関係を、頭の中ではなく画面の上で結びつけることが狙いです。

### 3. 5つのアルゴリズムを同一UIで比較できる

バブル・選択・挿入・クイック・マージの5種を、同じ操作パネルで切り替えられます。アルゴリズムごとの違いを「同じ入力で見比べる」ことで、それぞれの特徴が残りやすくなると考えました。選択ソートでは最小値マーカー（紫）を追加するなど、アルゴリズム固有の視覚フィードバックも実装しています。

### 4. フレームワークなしで状態管理を実装（Vanilla JS）

ReactやVueは使わず、ES6+ のみで実装しました。フレームワークに頼らずに「状態をどう持つか・どう更新するか」を設計することが、自分にとって一番の学習になると判断したためです。アルゴリズムのロジックは **Strategy Pattern** で分離しており、新しいソートを追加するときにUI側をほぼ変更しなくて済む構成になっています。

## アーキテクチャ概要

「アルゴリズムをリアルタイムで動かす」のではなく、先に **操作の全履歴（Step配列）を生成** してから、その配列を再生する構造です。

```
ソートロジック（sorts/*.js）
  └─→ Stepオブジェクト配列を生成
          └─→ setInterval で1ステップずつUI更新
                  └─→ バーチャート / コードハイライト / ログを同期描画
```

この方式のメリットは以下の通りです。

- **前後移動が簡単**: Step配列のインデックスを変えるだけで「戻る / 進む」が実現できる
- **表示とロジックが分離**: UIはStepを受け取って描画するだけ。ソートロジックに触れずにUIを変更できる
- **アルゴリズム追加が容易**: 新しいアルゴリズムの追加は、Stepを生成する関数を1つ追加するだけで済む

## インストール・実行方法

ビルドツール不要で、ブラウザだけで動きます。

```bash
git clone https://github.com/yourusername/visual-sort-suite.git
```

クローン後、フォルダ内の `index.html` をブラウザで開いてください。VS Code の **Live Server** を使うと変更が即反映されて便利です。
