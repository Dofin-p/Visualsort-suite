バブルソートに特化した学習ツール「Bubble Visualizer」の仕様書を作成しました。
シンプルながらも、「なぜ隣同士を交換するのか」を徹底的に理解させる設計にしています。

---

## 結論

本ツールは、配列の右端から大きな値が「泡（Bubble）」のように浮かび上がっていく様子を、ソースコードの実行行と同期させて視覚化する**バブルソート特化型エミュレーター**です。

---

## 1. 用語定義

* **隣接交換（Swap）**: 隣り合う2つの要素の大小を比較し、順序が逆であれば入れ替えるバブルソートの基本操作。
* **スキャン（パス）**: 配列の端から端まで1回比較を繰り返すこと。1回のスキャンで最大値が1つ確定する。
* **未確定領域**: まだ並び替えが終わっていない、比較対象となる範囲。

## 2. ユースケース / ユーザーストーリー

| ユーザー | ストーリー |
| --- | --- |
| **完全な初心者** | 隣同士が入れ替わる様子をアニメーションで見て、「一番大きい数字が右へ移動していく」ルールを直感的に理解する。 |
| **実装に悩む人** | `for (let j = 0; j < n - i - 1; j++)` の `i` や `-1` が何を意味するのか、コードハイライトと図解を照らし合わせて納得する。 |

## 3. 画面仕様（入力・表示・エラー）

### 表示・入力項目

* **メインビジュアル**:
* **棒グラフ**: 数値の大きさを高さで表現。
* **ステータス表示**: 現在の `i` (外ループ) と `j` (内ループ) の変数をリアルタイム表示。


* **コントロールパネル**:
* **カスタム入力**: 5〜10個の数値を自由に入力（例：`8, 3, 1, 5, 2`）。
* **再生操作**: 再生/一時停止、手動1ステップ送り（Next）、1ステップ戻り（Prev）。


* **コードビュー**:
* 右側にバブルソートの標準的なJavaScript/Cコードを表示し、現在実行中の行を黄色でハイライト。



### エラーハンドリング

* **要素数過多**: 15個以上の入力時は「画面に収まりきらないため、15個以下に調整してください」と表示。
* **不正な入力**: 全角数字や記号が含まれる場合は、「半角数字をカンマ区切りで入力してください」と警告。

## 4. データ設計（状態管理）

| 項目 | 型 | 初期値・例 | 役割 |
| --- | --- | --- | --- |
| `data` | `number[]` | `[5, 2, 9, 1]` | 現在の配列の状態 |
| `activeIndices` | `[number, number]` | `[0, 1]` | 現在比較・ハイライトしているインデックス |
| `sortedIndex` | `number` | `3` | すでに確定した（右端の）インデックス境界 |
| `isSwapping` | `boolean` | `true/false` | 交換アニメーション実行中のフラグ |

## 5. アルゴリズムとステップ実行設計

バブルソートの動きを以下の「3つの視覚状態」に分解して制御します。

1. **Comparison（比較）**: `arr[j]` と `arr[j+1]` を黄色で強調。
2. **Swap（交換）**: `arr[j] > arr[j+1]` の場合、赤色に変化して位置が滑らかに入れ替わる。
3. **Sorted（確定）**: 内側ループ終了時、一番右の要素を青色（確定色）に変更し、次回のスキャン対象から外す。

## 6. 非機能要件

* **性能**: アニメーションは `requestAnimationFrame` または CSS Transition を使用し、60fpsのスムーズな動きを実現する。
* **セキュリティ**: ユーザー入力フォームからの XSS 対策（サニタイズ）を徹底する。
* **ログ**: 画面下部に「8と3を比較：8の方が大きいので交換します」といった日本語の実行ログを表示する。

## 7. 受け入れ条件（テスト観点）

* [ ] 配列が完全に逆順（降順）の場合でも、正しく昇順にソートされること。
* [ ] すでにソート済みの配列を入力した際、無駄な交換が発生しない（または最適化コードが動く）こと。
* [ ] アニメーションの途中で「一時停止」しても、データの整合性が崩れず、そこから再開できること。

---

### 理解を助ける例え話：背の順の整列

バブルソートは、**「隣の人とだけ背比べをして、大きい人が右へ移動する」**というルールで列を整える方法です。
一番大きな人は、自分より大きな人がいない限り、どんどん右へとはじき出されていきます。この「一番大きい人が右端へ移動する」様子が、水の中の泡が表面に浮かび上がっていくように見えるため、バブルソートと呼ばれます。
