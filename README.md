# VisualSort Suite — ソートアルゴリズム可視化プラットフォーム

**Live Demo:** [https://dofin-p.github.io/Visualsort-suite/](https://dofin-p.github.io/Visualsort-suite/)

VisualSort Suiteは、ソートアルゴリズムの「コード上の処理」と「配列の変化」を**1ステップ単位で同期**させ、初学者がつまずきやすい“二重ループの中で何が起きているか”を直感的に理解できるようにした学習用Webアプリです。
単なる動画ではなく、入力値を自分で設定し、再生/コマ送りで確認できる**インタラクティブな学習体験**を重視して設計しました。

## 開発背景

プログラミング学習でソートは定番テーマですが、現場で見ていて（自分も含め）特に多いのが、

* ループ変数（i, j, minIdx など）が動いた結果、配列がどう変化したのか追えない
* 「比較」「交換」「確定」の概念が頭の中で混線する
* 結果だけ見て“わかった気”になるが、手で追うと崩れる

という状況です。
そこで本ツールでは、**コードとデータの動きを完全に同期**させ、ユーザーが自分のペースで確認できるUIに落とし込みました。

---

## 工夫点（設計の意図）

### 1) 「コード」と「動き」の完全同期（1行単位の理解）

* 実行中のコード行をハイライトし、同時に可視化側で **比較（黄色）・交換（赤）・確定（青）** をアニメーション表示します。
* 初学者が苦手な「変数の更新」と「配列の変化」を、頭の中ではなく画面上で結びつける狙いです。

### 2) 3つの基本ソートを同一UIで比較できる

* **バブル / 選択 / 挿入 / クイック / マージ** を同じ操作パネルで切り替え可能。
* 別々に学ぶより、同一画面で挙動を比較した方が「何が違うのか」が残りやすいと判断しました。
* 例：選択ソートは「最小値マーカー」など、アルゴリズム固有の視覚フィードバックも追加しています。

### 3) Vanilla JSで“状態”を扱い切る設計（拡張しやすい）

* フレームワークに頼らず、**状態管理の設計力**が見える実装を狙いました。
* 全操作を「Stepオブジェクトの配列」として事前生成し、UI操作（再生・前後移動）をそのStep列の参照で実現しています。
* ソートロジックは Strategy Pattern で分離し、将来的なアルゴリズム追加（クイックソート等）を想定した疎結合構成です。

## アーキテクチャ概要

本アプリは「アルゴリズムを動かす」のではなく、先に **“操作の履歴（Step列）”を生成**し、その再生でUIを動かす構造です。

* **メリット**

  * 前後移動（戻る/進む）を実装しやすい
  * 表示とロジックの分離が明確（UIはStepを描画するだけ）
  * アルゴリズム追加時に、UI側の修正範囲が小さい

## インストール・実行方法

ビルドツール不要で、ブラウザだけで動作します。

1. リポジトリをクローン

```bash
git clone https://github.com/yourusername/visual-sort-suite.git
```

2. 実行

* フォルダ内の `index.html` をブラウザ（Chrome / Edge / Firefox 等）で開いてください。
* もしくは VS Code の **Live Server** を使うと確認がスムーズです。
