## VisualSort Suite - アルゴリズム可視化プラットフォーム

### 📌 アプリの概要と3つの工夫点

**1. 「コード」と「動き」の完全同期による深い理解**

* アルゴリズムのロジックとデータの動きを、1行単位でリンクさせました。
* 初学者は「ループ変数の変化」と「配列の入れ替え」を頭の中で結びつけるのに苦労するためです。
* 実行中のコード行をハイライト表示し、同時にグラフ上で比較（黄色）・交換（赤）・確定（青）のアニメーションを行うことで、処理の流れを直感的に把握できるようにしました。

**2. 3大ソートアルゴリズムの比較・体感学習**

* バブル・選択・挿入ソートを同一UIで切り替え、挙動の違いを明確にしました。
* 個別に学ぶよりも、比較することで各手法のメリット・デメリット（計算量や交換回数の差）が記憶に定着しやすいためです。
* 共通の操作パネル（再生・コマ送り）を採用しつつ、アルゴリズムごとに固有の視覚フィードバック（選択ソートの「最小値マーカー」など）を実装し、それぞれの特徴を際立たせました。

**3. Vanilla JSによるステート管理と拡張性の高い設計**

* 外部フレームワークに頼らず、堅牢な設計パターンで実装しました。
* 基礎的なJavaScript力の証明と、将来的なアルゴリズム追加（クイックソート等）への対応を容易にするためです。
* 全操作を「Stepオブジェクト」の配列として事前生成する設計を採用。これにより「逆再生」や「特定ステップへのジャンプ」をバグなく実現し、ソートロジック部分はストラテジーパターンを用いて分離・疎結合に保っています。

### 💡 開発背景

プログラミング学習において、ソートアルゴリズムは最初の壁の一つです。「二重ループの中で何が起きているのかイメージできない」という課題を解決するため、**「見て、動かして、納得する」**体験を提供したいと考え、本ツールを開発しました。
単なる動画ではなく、ユーザー自身が入力値を設定し、自分のペースでステップ実行できる「インタラクティブ性」を重視しています。

### ✨ 機能一覧

* **アルゴリズム選択機能**
* **バブルソート**: 隣り合う要素の交換による整列過程を可視化
* **選択ソート**: 最小値の探索と交換のプロセスを可視化（新規追加）
* **挿入ソート**: 要素の挿入位置を探してシフトする動きを可視化（新規追加）


* **再生コントロール**
* 自動再生 / 一時停止 / 前へ / 次へ
* シークバーによる任意位置へのジャンプ（実装予定）


* **カスタム入力**
* カンマ区切りでの数値入力
* 入力値バリデーション（数値チェック、要素数制限）


* **リアルタイムステータス**
* 変数（i, j, minIdx等）の現在値を表示
* 実行ログ（「8と3を比較」「交換が発生」など）の表示

### 🚀 インストール・実行方法

特別なビルドツールは不要です。ブラウザのみで動作します。

1. **リポジトリのクローン**
```bash
git clone https://github.com/yourusername/visual-sort-suite.git

```


2. **実行**
* フォルダ内の `index.html` をブラウザ（Chrome/Edge/Firefox等）で開いてください。
* または、VS Codeの「Live Server」拡張機能を使用するとスムーズに確認できます。
